## Known issue: Valibot `toStandardJsonSchema()` with `v.check()` on SDK v2

This run registered the Valibot schemas with plain `toStandardJsonSchema(schema)` once, without the workaround. `tools/list` failed with: `The "check" action cannot be converted to JSON Schema.`. The measured Valibot server uses a wrapper that passes `libraryOptions: { ignoreActions: ['check', 'partial_check'] }` (see README).
